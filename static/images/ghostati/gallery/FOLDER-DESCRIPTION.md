participant consented to publication. The five JPEGs are deterministic web
exports of the supplied source images: maximum width 1800 px, no generative
retouching and no changes to the documented makeup patterns.

the time of the test. Gallery cards can optionally include a silent looping
MP4 below their caption. `ghostati-linee-bicolore-check.mp4` is the cropped,
